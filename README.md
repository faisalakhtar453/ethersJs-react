A React DApp connecting to an Ethereum smart contract on Sepolia testnet. Interact with the contract to read values, set values, send ETH to the contract, and withdraw ETH.

Features
Display contract name, stored value, and balances

Set a new stored value

Send 0.001 ETH to the contract

Withdraw 0.001 ETH to user wallet

Uses MetaMask and Infura Sepolia provider
